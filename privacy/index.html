Политика конфиденциальности

Настоящая политика описывает порядок обработки данных, которые пользователь оставляет через формы сайта.

Какие данные собираются

Имя, телефон, сообщение, адрес страницы, UTM-метки и техническая информация, необходимая для обработки заявки.

Для чего используются данные

Для связи с пользователем, консультации, подготовки предложения и улучшения качества сайта.

Передача третьим лицам

Данные не передаются третьим лицам, кроме случаев, предусмотренных законом или необходимых для обработки заявки.
